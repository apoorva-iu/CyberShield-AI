# Candidate 1 - Recruitment Scam (EMSCAD)

## Purpose

This folder contains the research and evaluation of the Recruitment Scam dataset (EMSCAD), considered as Candidate 1 for the Fake Job Detection module in CyberShield-AI.

## Objective

The purpose of this evaluation is to determine whether the dataset is suitable for building an AI-powered fake job detection system.

## Current Status

🟢 Evaluated

## Evaluation Summary

- Real-world dataset
- Widely used in research
- Rich textual and metadata features
- Strong candidate for explainable AI
