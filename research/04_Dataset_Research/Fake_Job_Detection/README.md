# Fake Job Detection Research

## Purpose

This folder contains all research related to the Fake Job Detection module of CyberShield AI.

The goal is to identify the most suitable dataset, perform exploratory data analysis, compare different machine learning models, and develop an explainable AI model capable of detecting fraudulent job postings.

## Research Workflow

1. Search and compare datasets
2. Select the best dataset
3. Perform Exploratory Data Analysis (EDA)
4. Clean and preprocess the data
5. Engineer useful features
6. Train multiple machine learning models
7. Compare model performance
8. Select the best model
9. Integrate the model into CyberShield AI
10. Add Explainable AI and Risk Scoring
