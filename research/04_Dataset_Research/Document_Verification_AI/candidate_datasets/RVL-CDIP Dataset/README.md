# RVL-CDIP Dataset

## Overview

The RVL-CDIP (Ryerson Vision Lab – Complex Document Information Processing) Dataset is one of the most widely used benchmark datasets for document image classification. It contains scanned document images from multiple real-world document categories and is extensively used in research involving document understanding, document classification, and intelligent document processing.

The dataset enables machine learning and deep learning models to recognize and classify different document types based on their visual structure and layout.

- Visual Document Recognition
- Intelligent Document Processing
- Deep Learning for Document Analysis

## Dataset Categories

The dataset contains 16 document classes:

- Letter
- Form
- Email
- Handwritten
- Advertisement
- Scientific Report
- Scientific Publication
- Specification
- File Folder
- News Article
- Budget
- Invoice
- Presentation
- Questionnaire
- Resume
- Memo

---

## Dataset Contents

The dataset consists of scanned grayscale document images collected from real-world office documents.

Each document belongs to one of the predefined document categories used for document classification tasks.

## Role in CyberShield-AI

The RVL-CDIP Dataset has been selected as **Candidate 2** for the Document Verification AI module.

Within CyberShield-AI, this dataset will be used to:

- Identify document types
- Understand document layouts
- Classify uploaded documents
- Improve document verification accuracy
- Support downstream authenticity verification

## Advantages

---

## Limitations

- Does not provide OCR annotations
- Does not contain forged document labels
- Not designed for document tampering detection

---

## Conclusion

The RVL-CDIP Dataset is an industry-standard benchmark for document classification and layout understanding. It complements OCR datasets by enabling AI models to recognize document categories before performing document verification and authenticity analysis. It serves as the second core dataset in the Document Verification AI pipeline of CyberShield-AI.
