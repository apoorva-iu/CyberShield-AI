# Project Scope

## Current Scope (Version 1.0)

The current version of CyberShield AI focuses on developing a robust AI-powered cybersecurity platform capable of detecting and analyzing common cyber fraud scenarios.

### Included Modules

- Fake Job & Internship Detection
- Phishing URL Detection
- Scam Message Detection using OCR
- Fake Document Verification
- Explainable AI-based Fraud Analysis
- Fraud Risk Scoring
- User Authentication
- Dashboard & Analytics
- Blockchain-based Tamper-proof Verification
- Verification History
- MongoDB Database
- REST API Integration

---
