# Project Objectives

## Primary Objectives

- Detect fake job and internship postings using Artificial Intelligence.
- Detect phishing URLs and suspicious websites.
- Detect scam messages from screenshots using OCR.
- Verify uploaded documents for authenticity.
- Generate an explainable fraud risk score.
- Store verification evidence securely using blockchain.

## Secondary Objectives

- Provide detailed fraud reports instead of simple predictions.
- Build an intuitive dashboard for users.
- Maintain secure verification history.
- Support future integration with browser extensions and DigiLocker.
