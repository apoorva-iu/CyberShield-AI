# Proposed System

CyberShield AI integrates multiple cybersecurity modules into a single platform.

The system combines:

- AI-based fake job detection
- OCR-based screenshot analysis
- Phishing URL detection
- Document verification
- Fraud risk scoring
- Explainable AI
- Blockchain audit trail

The platform generates detailed fraud analysis reports instead of simple binary predictions, enabling users to understand why an item is classified as suspicious.
